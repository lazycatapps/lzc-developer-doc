# 社区激励规则

为了让懒猫微服的应用越来越多，越来越好用，我们为社区贡献者准备了红包奖励与打赏机制：

#### 1. 应用激励与打赏机制

为了鼓励更多高品质应用的涌现，懒猫商店实行“下载量达标激励 + 用户打赏”的双轨道激励模式。只要应用成功上架，不再限制特定应用类型，均可参与以下激励：

* **应用下载量达标激励**：应用移植或原创上架后，当应用在懒猫商店的累计下载量突破 **100 次**时，官方将直接发放 **100 元**现金激励红包（通过商店打赏方式执行）。
* **用户打赏通道**：所有优质应用上架和更新均可开启打赏通道。除了官方达标激励外，开发者可持续获得来自真实用户的直接打赏收益，收益上不封顶。

#### 2. 编写商店应用攻略

配合本次激励机制升级，**所有攻略教程类内容均不再发放官方奖励红包**。

虽然没有现金激励，但我们依然鼓励开发者与创作者分享应用的使用心得。只要攻略内容真实、准确且符合基本规范，均可正常审核上架。

**为什么我们依然鼓励编写攻略？**

1. **辅助应用审核**：对于功能复杂的应用，提供详尽的用户指南或操作攻略是**复杂应用顺利通过审核的必要前提条件**。
2. **提升下载与打赏收益**：优秀的攻略能帮助新用户快速上手，有效提升应用的下载量（助您更快达成100次下载的官方激励）和用户留存，从而间接增加应用的用户打赏收益。

**攻略上架的基本规范：**

* **真实有效**：所有操作步骤需基于实际测试，确保用户能顺利复现。
* **图文并茂**：建议包含实际的软件界面截图，并明确关联应用商店的链接。
* **场景明确**：针对应用的典型使用场景提供指导，避免仅对单一按钮进行无上下文的浅显描述。

*注：对于开箱即用的简单工具类软件，虽无需复杂攻略即可上架，但分享实用技巧依然会受到社区的欢迎。*

#### 3. 小龙猫技能上架

为了保证小龙猫Skill的质量和安全性（防范网络Skill盗取用户数据等风险），Skill的审核会异常严格，Skill质量不够高或者用处不大都不会审核通过。Skill上架时没有初始激励，官方会对审核过的Skill，后期根据下载量进行激励候补。

#### 4. 不能上架应用商店的应用类型

目前黄、 赌、 毒、 空投、 破解软件或者违反中国法律的软件不能上架应用商店。

#### 5. 应用审核主观标准

为构建高品质应用商店，就开发者上传应用的主观审核标准明确如下：

* **相似应用审核**：若提交的应用与商店内已上架应用存在较高相似度，主观评审将采取更为审慎的尺度，原则上不予上架；但若该应用具备显著的创新性功能，或能有效解决现有应用无法满足的需求，可酌情予以通过。
* **功能及界面质量审核**：对于功能过于简易、无实用性、前端界面粗糙的应用，因整体品质未达标准，主观评审不予通过，不予上架。
* **本地化要求**：应用如仅提供纯英文界面或英文操作指南，缺少必要的本地化支持，不予上架。（补充：如果该项目比较受欢迎，项目质量比较高，最终审核意见由审核人员判定。）
* **复杂功能应用审核**：功能复杂但缺乏详尽攻略说明的应用，开发者须补充完整的用户指南或操作攻略，经重新审核通过后方可上架。

其他未说明的情况，审核最终结果解释权由懒猫微服团队所有。

::: warning

2.  如果应用有上传/下载功能，需要接入懒猫网盘的自动拦截文件选择器，未接入无法在懒猫商店上架。[参考文档](./lazycat-file-picker-auto-intercept.md)
